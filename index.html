FILE 02

六条红线：碰哪条都不划算

↑ top
  1. 不碰淫秽物品的传播链路 制作、复制、出版、贩卖、传播，只要以牟利为目的且达到入罪标准，即按刑法相关条文追责；为站点引流、做分发入口、挂推广返佣，也可能被认定为共犯环节。 刑法第三百六十三条 · 传播淫秽物品牟利罪
  2. 不「免费」搭无证视听服务 在国内提供影视点播，ICP 备案替代不了《信息网络传播视听节目许可证》；无证登载视听节目，轻则警告罚款，重则按非法经营活动处置。 《互联网视听节目服务管理规定》
  3. 不把「聚合链接」当护身符 对盗版片源做分类、编辑、推荐、搜索排序后再交到点播页，属于传播行为；「我只放链接、广告也不赚钱」不构成当然免责。 信息网络传播权 · 避风港规则的适用前提
  4. 不把「为爱发电」当非营利 页面挂了广告联盟、充值会员、虚拟币、打赏或导流佣金，司法实践中通常仍按「以营利为目的」认定，金额直接决定量刑档。 侵犯著作权罪的「营利目的」认定
  5. 短内容也别漏合规 微短剧按题材与投资分三类管理，一、二类须许可证或省级批准文件，三类由播出单位播前审核并标注节目编号；低俗、擦边内容另受内容审核口径约束。 微短剧分类分层管理要求
  6. 下线不是删页面就完事 域名停用要同步关解析、注销备案；否则被抢注成盗版/低俗镜像，原持有人可能被连带追责。 域名与备案主体的持续管理义务
FILE 03

自查清单：打算做站的人逐条勾

print #
  • 片源授权能拿出链条吗？从制片方/发行方到你的播放端，每一环都有书面授权；只有「网上扒来的」一律不能用。授权缺失 = 地基是空的，技术再漂亮也没用。
  • 视听许可证在有效期内吗？ICP 备案 + 视听许可证双齐，且经营范围覆盖你要做的业务类型。只备案不持证，被查是常态不是意外。
  • 内容审核机制写进流程了吗？上传前审、播中巡查、举报 24 小时响应、违规下架留痕，低俗与涉黄关键词要有拦截规则。平台责任看的是机制，不是一句「网友上传的」。
  • 赚钱方式经得起问吗？广告联盟、会员、打赏、导流佣金逐条列清；沾「充值返利/提现/虚拟币结算」的直接砍掉。这几项是同类案里认定营利的铁证。
  • 有没有「切换源 / 专用播放器 / 改 DNS」？有其中任何一个，说明你做的是盗链基建，不是合规产品。用户要你教他绕，本身就是红旗。
  • 备案主体、包名、开发者主页一致吗？三者对不上，应用商店审核过不了，用户也认不出你是谁。同名撞车是常态，闭环才是身份。
  • 出事之后能立刻止血吗？下架 SOP、证据留存、侵权投诉通道、公安/网信联络人都要有，别等封了才找人。处置速度决定责任大小。

FILE 05

依据索引：自己核对用

↑ top
  • 刑法第三百六十三条——制作、复制、出版、贩卖、传播淫秽物品牟利罪；第三百六十四条为传播淫秽物品罪（非牟利）。入罪标准与量刑档，以现行法条与司法解释为准。
  • 《互联网视听节目服务管理规定》——从事互联网视听节目服务须取得许可证，备案不等于持证。国家广电总局、工信部双口径，别只盯备案号。
  • 《信息网络传播权保护条例》/ 著作权法——未经许可通过信息网络提供作品，属侵权；避风港以「不知情 + 接通知立即删除」为前提。「我只存链接」不是豁免条款。
  • 微短剧分类分层管理口径——一、二类须许可证或省级批准文件，三类由播出单位播前审核并标注节目编号，AI 生成内容另需标识。短内容不是法外之地。
  • 平台与广告联盟规则——主流应用商店、支付与广告平台均对色情、盗版、诱导充值设拒绝上线条款。上不了架、结不了款，产品就活不成。

以上是合规自查的方向索引，不是法律意见。真要上线，请让执业律师按你的业务模型出一版合规意见，别照着网页抄。

FILE 06

常见疑问

↑ top
  • 「我只是个静态页，什么都没放，犯法吗？」单纯说明与科普、不指向任何资源、不引流、不接变现，风险极低；但页面一旦开始列站点、写「备用地址」、挂推广，性质就变了。红线在「有没有把人送往内容」。
  • 「我不赚钱，只是分享资源」能免责吗？」不能。非营利只影响量刑轻重，不改变侵权或传播违法性质的认定；传播淫秽物品罪还有专门的「非牟利」条文。别拿「免费」当护身符。
  • 「别人都这么干，查不到我」靠谱吗？」不靠谱。同类站被封、运营者被追、域名原主被连带起诉的案例都公开可查，运气不是风控方案。被查是时间问题，不是概率问题。
  • 「我就想做个正常的影视站，怎么才干净？」三条：只上拿得到授权的片、持证+备案双齐、审核与下架机制留痕；变现只走正规贴片广告或平台分账，不碰充值返利。走正路成本高，但这是唯一能长期活下来的路。
  • 这个页面会不会反而被当成那种站？」不会。全文无片单、无站点名（辨析表里只写「风险形态」不列具体域名）、无入口、无 Logo 借用，首屏与页脚双重非官方声明；做成说明页而不是影视站，就是这个目的。搜索引擎看的是实做，不是名字。
